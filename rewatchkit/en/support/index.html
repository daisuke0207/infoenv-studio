Start in three steps

  1. Open a regular YouTube video in desktop Chrome, then open RewatchKit.
  2. In Clips, use Start here and End here, enter a name, then Save clip. Check the saved confirmation and the saved clip.
  3. Repeat the saved clip, or open Studio to find clips by video and add them to playlists in your preferred order.

Notes and chapters

Choose Add note, enter text and Save note. Select a saved timestamp to return to that moment. Chapter timestamps work the same way. Chapter discovery may find nothing when the description or loaded comments do not contain timestamps; manual entry is available.

Tabs stay at the top while you scroll a long chapter list. Returning to a tab restores its previous position within the same open panel. Scroll positions are not persisted after closing the panel.

A saved item seems missing

Check for the saved confirmation. If saving fails, keep your input and use the displayed retry action. A clip needs an end time after its start time. Clear Studio search filters and expand the video's group. Different Chrome profiles or extension IDs do not share saved data.

Playback will not start or stops

Return to the YouTube tab and check that the video can play. If the browser blocks automatic playback, press Play on YouTube. Range controls wait during a detected advertisement. An unresponsive preparation step eventually displays an error with a retry action. Recovery from every real advertisement or restriction is not guaranteed.

Pause retains the current clip and position; Resume continues. End playback releases range control. Switching videos uses normal YouTube pages, so playback is not a seamless join of video files.

Old UI or errors remain after an update

A YouTube page left open during an extension update can retain old code. Confirm your input has been saved, then reload that page once. Do not uninstall the extension or clear storage as the first recovery step.

Backup and moving installations

Use Export notes and clips (drafts excluded) in Studio to save a JSON file. It includes committed notes, chapters, clips and playlists. Uncommitted drafts are excluded. The file can contain private information: do not post it publicly.

Review an import before merging it with existing data. Importing identical content twice does not add duplicates; conflicting notes are preserved separately. Changing extension IDs does not transfer data automatically. Keep the original extension and backup while checking the destination. Do not remove the original before verifying the transfer.

Supported scope

Regular YouTube videos in desktop Chrome, in Japanese and English. Shorts, live streams, mobile and other sites are not guaranteed. There is no account, cloud sync, video download/editing or AI summary feature. Thumbnails represent the whole video.
