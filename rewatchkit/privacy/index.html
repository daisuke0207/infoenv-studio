1. 何を取り扱うか

拡張機能は、表示中の対応YouTube動画のID、URL、タイトル、現在の再生時刻、動画の長さ、再生状態を取得して、利用者に時刻付きのメモ・目次・クリップ・区間再生機能を提供します。

利用者が保存したメモ本文、メモの時刻、クリップの開始・終了時刻と名前、動画をまたぐ再生リストとその並び順、手動目次、設定（言語・テーマ・最後に選択したタブ）、保存前の下書きも扱います。再生バーのマーカーには保存したメモやクリップの時刻だけを使用します。

目次候補を探す機能では、YouTubeページで既に読み込まれている動画の概要欄やコメントのテキスト、および対応する動画のメタデータを利用することがあります。これは目次・時刻表示のためであり、YouTubeの全視聴履歴を集める機能ではありません。

2. 保存と利用目的

保存データはChromeの拡張機能用ローカルストレージ（chrome.storage.local）に保存され、対応する動画に戻ったときの表示・検索・再生と、利用者自身のバックアップ書き出し・取り込みに使用します。開発者が運営するサーバーへのメモ・クリップ・閲覧情報の自動送信やクラウド同期は実装していません。 アカウント登録も不要です。

chrome.storage.local の保存内容を、エンドツーエンド暗号化されている、バックアップされている、他のPCに同期されるとは保証しません。

3. 外部サービスとの通信・共有

  • 通常の動画再生・時刻への移動はYouTubeページの機能を使用します。YouTube/Googleには、通常のYouTube閲覧や動画・画像の読込に伴うネットワーク通信が発生します。
  • Studioに動画サムネイルを表示する際はYouTubeの公開サムネイルサーバー（i.ytimg.com）へ画像をリクエストします。画像URLには動画IDが含まれ、通信元IPアドレス等の情報がYouTube/Google側へ渡り得ます。メモ本文・クリップ名・再生リストは画像URLに含めず、参照元URLも送らない設定です。
  • メモ本文・クリップ名・再生リストの内容を開発者サーバーや第三者へ自動アップロードする機能はありません。 利用者がエクスポートしたJSONの扱いは、利用者の保存・共有操作に依存します。
  • 現行版には、利用状況を開発者へ送信する分析SDK、広告配信SDK、行動ターゲティング、保存情報の販売機能はありません。

YouTubeでの通常の閲覧データの扱いは、YouTube/Google自身のプライバシー関連文書が適用されます。本拡張はYouTubeまたはGoogleの公式製品ではありません。

4. 利用者によるデータ管理

Studioまたはサイドパネルから保存データを確認・削除できます。統一JSONバックアップでは、確定したメモ・目次・クリップ・再生リストを書き出し、端末に保存し、利用者自身で再取り込みできます。未確定の下書きは統一バックアップの対象外です。

動画単位の削除では関連するクリップを再生リストからも外します。未確定下書きの削除は別途明示確認が必要です。取消・削除後には、古い書き込みで本文が復活することを防ぐ、本文を含まない削除マーカーが残る場合があります。書き出したファイルは拡張内の削除とは別に端末へ残るため、利用者自身で管理してください。

保存データは利用者の操作による削除、Chromeプロフィールの削除、拡張機能のアンインストール等により利用できなくなる場合があります。重要なデータについては、本人が安全な場所へバックアップを保存してください。

5. 保護とChromeの権限

拡張機能は機能に必要な storage、sidePanel、scripting を利用し、動画ページへのアクセス権限は https://www.youtube.com/* に限定します。メモ本文の読み書きは拡張機能の信頼された画面とバックグラウンド処理で行い、YouTubeページのスクリプトには保存メモ本文を渡しません。

ただし、利用者の端末やChromeプロフィールの保護、Chrome自体の脆弱性対策、データの永続保持について絶対的な保証はしません。

6. ポリシーの遵守・改訂

Chrome Web Store User Data Policy（Limited Use要件を含む）に従い、取得した情報を説明済みの単一の製品目的に必要な範囲でのみ利用します。個人向け広告、データ販売、目的外のデータ転送は行いません。

取扱うデータや目的が変わる場合は、この文書とストアのデータ取扱い申告を更新し、必要な追加説明・同意取得を行います。

7. このウェブサイトとお問い合わせ

この案内サイトはCloudflare Pagesで配信します。ページの配信・セキュリティのため、CloudflareがIPアドレス、要求URL、ブラウザ情報などの通信情報を処理します。RewatchKitの案内ページには、独自のアクセス解析、広告、外部フォント、Cookieを設定する処理を追加していません。Infoenv Studioのトップページでは言語設定のCookieを使用します。このウェブサイトから拡張機能内の保存データへアクセスすることはありません。

お問い合わせを送った場合、Infoenv Studioは送信元メールアドレス、件名、本文、添付された情報をGoogle Workspace経由で受け取り、返信・問題の調査・対応の継続に必要な範囲で使用・保持します。宣伝目的での利用や販売は行いません。問い合わせ情報の確認・訂正・削除の希望は、同じ窓口で受け付けます。法令上の義務や不正防止のため保持が必要な場合を除き、必要性を確認して対応します。メモ本文・個人バックアップ・Cookie・パスワードは送らないでください。
